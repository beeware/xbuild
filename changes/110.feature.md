`xvenv` and `xbuild` now support Emscripten (Pyodide) on Python 3.12-3.14. `--platform emscripten` downloads the matching Pyodide cross-build environment, installs the required version of the Emscripten SDK if `emcc` isn't already available, routes compiler invocations through the Emscripten toolchain (via a port of pyodide-build's `pywasmcross` wrapper), and installs a `pip` that accepts `pyodide_*`/`pyemscripten_*` wheels.
