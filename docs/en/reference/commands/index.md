# Command reference

`xbuild` provides three commands:

- [`xbuild`](./xbuild.md) - Build a wheel for a target platform
- [`xvenv`](./xvenv.md) - Convert a virtual environment into a cross-platform virtual environment
- [`xpython`](./xpython.md) - Run a Python module inside an iOS Simulator or Android emulator/device

## Common options

The following options are available on all three commands.

### `-h` / `--help`

Display the available options for the command, and a description of usage.

### `-V` / `--version`

Print the version of the command being used.

### `-v` / `--verbose`

Increase the verbosity of output generated by the command. Can be specified multiple times (e.g. `-vv`) to increase verbosity further.

### Specifying the target platform { #target-platform }

Every command needs to know which target platform's Python to use. Specify it with exactly one of [`--platform`][opt-platform], [`--build-details`][opt-build-details], or [`--sysconfig`][opt-sysconfig].

If the command is run from *inside* an active cross-platform environment (one created by `xvenv`), these options can be omitted. The command will then use the same target-platform Python that was used to create the current environment. If one of these options *is* provided, it takes precedence over the current environment.

Cross-platform environments created by `xvenv` 0.4.0 or earlier don't record this information; recreate the environment, or pass one of the options explicitly.

### `--build-details PATH` { #opt-build-details }

The path to a `build-details.json` file describing a pre-existing target-platform Python build (Python 3.14+ format).

Mutually exclusive with [`--sysconfig`][opt-sysconfig] and [`--platform`][opt-platform].

### `--sysconfig PATH` { #opt-sysconfig }

The path to a `_sysconfigdata__*.py` file describing a pre-existing target-platform Python build (legacy format, Python ≤3.13).

Mutually exclusive with [`--build-details`][opt-build-details] and [`--platform`][opt-platform].

### `--platform PLATFORM` { #opt-platform }

Download (or reuse a cached copy of) a Python build for the named target platform (one of `ios`, `android`, or `emscripten`).

Mutually exclusive with [`--build-details`][opt-build-details] and [`--sysconfig`][opt-sysconfig].

### `--arch ARCH`

The target architecture to use with [`--platform`][opt-platform]. Defaults to a useful value based on the host machine's architecture. Only valid in combination with [`--platform`][opt-platform].

### `--cache PATH`

The directory to use for caching downloaded Python builds, for use with [`--platform`][opt-platform]. If unspecified, the location defined by the `XBUILD_CACHE` environment variable will be used; if that variable isn't defined, a platform-appropriate user cache directory will be use.d See [Environment variables](../environment-variables.md). Only valid in combination with [`--platform`][opt-platform].

### `--archive PATH`

Use an already-extracted Python build at `PATH` instead of downloading one, for use with [`--platform`][opt-platform]. `PATH` must be laid out the same way an archive downloaded via `--platform` would have been unpacked. Mutually exclusive with `--cache`. Only valid in combination with [`--platform`][opt-platform].
